How to use
  1. Inspect a model. Choose a built-in dataset. Use Point cloud to see individual points, or Surface for shaded surfels. Drag to rotate, scroll to zoom, and double-click to reset the camera.
  2. Explore the budget. Lower Point budget, choose a selection method, then play a camera path. Toggle stability control to inspect point changes.
  3. Compare and export. Run budget comparison to test all methods with shared settings, then export results JSON. Save frame downloads the current view.

For an easy first example, select Jumbo Jet. Full-point reference shows all points and bypasses the budget. Use a colored synthetic scene to evaluate the color-contrast term; the bundled mesh-derived models have no source colors.

Measurement notes

Comparisons use surface rendering, Original material and standard depth shading, including when launched from Point cloud view. The same sunlight settings are used for every method. Presentation backgrounds are excluded from image measurements.

Synthetic scenes validate functionality, not performance on real scans. Color contrast is an appearance proxy. Interactive selection runs at up to 30 Hz; experiments use a fixed 30 Hz. RAF FPS is not a GPU-only timing measurement.
