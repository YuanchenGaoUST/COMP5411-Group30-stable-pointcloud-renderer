# Validation archive

The JSON reports in this directory preserve the original functionality checks and measured diagnostic values. Dates in directory names identify the corresponding validation runs. SwiftShader timings are diagnostic and are not native-GPU benchmarks.

Early screenshots of the retired Chinese interface are no longer included in this public archive. The original images remain in the local project backup; their JSON results have not been changed or replaced with new measurements.

For current English presentation images, use [the interface preview](../../docs/images/viewer-interface.png), [point-cloud view](../../docs/images/viewer-point-cloud.png), and [capture settings](../../docs/images/capture-manifest.json).

The existing browser smoke scripts can generate new screenshots in an output directory such as `results/local/`; see the [test instructions](../../README.md#optional-browser-integration-tests). Do not treat newly generated images as screenshots from an older archived run.
